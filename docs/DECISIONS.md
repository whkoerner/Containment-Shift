# Implementation decisions — 2026-10-08

## D-001 Accepted architecture
Keep existing docs/architecture/ decision package authoritative. Unity 6.3 LTS, C#, intended URP visual pipeline, host-owned world and pure-C# domain boundaries. Reason: small-team maintainability and explicit deterministic discrete simulation boundaries. Status: accepted design, implementation UNVERIFIED.

## D-002 Phase 1A development checkpoint
Select editor candidate **6000.3.25f1** (Unity-published changeset e1dba0a9aba4), Unity Input System **1.20.1**, URP dependency **17.3.0**, and Unity Test Framework **1.6.0**. Versions checked against published Unity release/package docs; actual combined Unity import/compilation and Package Manager resolution NOT RUN. Lock file will be generated by a verified Unity import; do not write a fabricated packages-lock.json. URP package exists in manifest but no serialized URP renderer/pipeline asset is yet configured — built-in fallback rendering/lighting is acceptable solely for the throwaway graybox.

The Input System package installer may prompt for changing active input handling and restarting the Editor. Accept New Input System, restart, then confirm the setting in Player Settings before judging controls. The direct Keyboard/Mouse calls are intentionally **prototype-only**; the reviewed command/input-action pathway is deferred to network integration.

## D-003 Defer installing networking SDK until a dedicated Gate A integration PR
Astra's FishNet 4.7.3R is a **spike candidate, not a production commitment**. Do not mix FishNet with NGO/Mirror/Fusion. Install FishNet from a verified immutable release (with license inventory) once Unity editor import and local collision behavior are confirmed. Run two and four real instances before freeze. No client authority for world state.

## D-004 Editor-generated graybox instead of hand-authored Unity scene YAML
A Unity Editor menu creates the actual scene using Unity APIs, registers it in build settings, and refuses overwrite. This avoids pretending a text-authored prefab is Unity-validated. It makes initial setup one deliberate menu action; generated scene and .meta must then be checked in after import verification.
