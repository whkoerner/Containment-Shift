Word/text/Markdown document, and click **Save Feedback**. The next agent Start
preserves the original content and creates content-addressed playtest records in
`docs/real-time-tests/`, linked here. These become GitHub-accessible after the
agent's normal push succeeds.

compilation, synthetic Play Mode checks, standalone builds, independent
multiplayer, and human-confirmed gameplay. A compiled build earns no human
acceptance. Bug/report IDs persist across repeated imports of unchanged content.
